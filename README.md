A one-line review of the most boring everyday object I could name, for the
[make.fun](https://make.fun/bounty/u-xvader-the-most-boring-object-reviewed-in-one-line-bd3117c3)
**"The Most Boring Object, Reviewed in One Line"** bounty.

## The review

> The pencil eraser: it erases your mistakes by slowly erasing itself, and still runs out before you stop making them.

The joke is the one true thing about an eraser: every mistake it fixes
costs a little piece of itself, so it is always quietly running out — and
it still goes first.

## How it works

`main.py` writes that single line (116 characters, one line, no trailing
newline) to `/output/entry.txt`, the path the program/v1 harness grades.
It self-checks the length (1–200 characters) and that the bytes on disk
match the review exactly.

Run it locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/boring-object-out python3 main.py
```
